# Developer Profile Card

A simple, clean, and responsive Developer Profile Card built using **HTML and CSS**. This project displays a developer's basic information, short bio, and social media links in a modern card layout.

## 📌 Project Overview

The Developer Profile Card is a beginner-friendly frontend project created to practice HTML structure, CSS styling, and Git/GitHub workflow.

It features a dark-themed design with a gradient avatar, profile information, interactive buttons, and hover effects.

## ✨ Features

- Clean and modern profile card design.
- Dark-themed user interface.
- Gradient circular avatar.
- Developer name and professional tagline.
- Short biography section.
- GitHub profile link.
- LinkedIn profile link.
- Email contact link.
- Hover effects on buttons.
- Responsive layout for different screen sizes.
- Smooth CSS transitions.

## 🛠️ Technologies Used

- **HTML5** – For structuring the webpage.
- **CSS3** – For styling, layout, colors, and hover effects.

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Open the project folder.
3. Make sure `index.html` and `style.css` are in the same folder.
4. Open `index.html` in your web browser.
